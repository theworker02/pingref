# pingref

Ping HTML/Markdown ref fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/pingref/

## Install / run

```bash
git clone https://github.com/theworker02/pingref.git
cd pingref
node src/cli.js
node --test
```
